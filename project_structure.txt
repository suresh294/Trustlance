Trustlance repository structure

frontend/
  React + Vite client
  src/services/web3.js — wallet connection and contract access
  package.json — frontend scripts and dependencies

backend/
  FastAPI application and API routes
  AI verification pipeline
  Oracle service that records scores on-chain

blockchain/
  Solidity escrow and reputation contracts
  Hardhat configuration, deployment scripts, and tests

smart_contract/
  Solidity source references

test_data/
  Local development/test samples

Root files:
  README.md — setup, product flow, configuration, and limitations
  requirements.txt — Python dependencies
  *_submissions_store.json — local sample/submission data; review before committing real user data

The current web application targets Polygon Amoy testnet. Keep secrets in ignored environment files and do not use real funds with this prototype.
